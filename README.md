# Frontend Learning Projects

This repository contains a collection of frontend practice projects built while learning HTML, CSS, JavaScript, React, and Tailwind CSS.

## Project Structure

- `react-1/` - React + Vite app with a login page UI
- `practice/` - HTML, CSS, and JavaScript practice exercises
- `task/` - mini frontend tasks and assignments
- `javascript.txt` - JavaScript notes
- `reactjs.txt` - React notes
- `tailwind.txt` - Tailwind CSS notes

## React Project

The `react-1` folder is a React application created with Vite. It includes:

- split layout design
- login form
- email and password validation
- password visibility toggle
- logged-in success state
- component-based React structure

## Technologies Used

- HTML
- CSS
- JavaScript
- React
- Vite
- Tailwind CSS

## How to Run

```bash
cd react-1
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Learning Goals

This project is focused on:

- building responsive UI
- using React components
- working with state and hooks
- practicing form validation
- creating frontend mini projects

## Summary

This workspace is a frontend learning repository for practicing web development through small projects, daily tasks, and React-based UI work.
