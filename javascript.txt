                      console.log(y)

operators: increment & decrement 
 
          post increment(a++)& decrement(a--)- when a variable see the same variable again it will get increased
    
          eg: var a=10              
              var b=a++ 
              console.log(b) -> o/p- 10
              console.log(a) -> o/p-11

          pre increment(--a) & decrement(--a)- the variable doesn't need a same variable to incre or decre.
 
          eg: var a=10
              var b=++a
              console.log(b) ->o/p -11
